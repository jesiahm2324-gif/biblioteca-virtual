# Biblioteca Virtual

App para leer en el teléfono leyes, códigos, normas y manuales, también sin internet.

## Cómo agregar documentos

Suba los PDF dentro de la carpeta `documentos`, en la subcarpeta de su área:

- `documentos/codigos`
- `documentos/laboral`
- `documentos/portuario`
- `documentos/pecuario`

El nombre del archivo es el título que se ve en la app. Por ejemplo, `Codigo-del-Trabajo-Ley-185.pdf` aparece como "Codigo del Trabajo Ley 185".

Cada archivo puede pesar hasta 25 MB si se sube desde la página de GitHub.

Este repositorio es público: suba aquí solo leyes y documentos públicos. Los libros y manuales con derechos de autor se agregan desde **Mis documentos** dentro de la app, y quedan solo en el teléfono.
